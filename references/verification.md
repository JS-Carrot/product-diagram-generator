# 交付前三段校验

图这类产物有个特点：**语法全对也可能难看，代码全绿也可能读不懂。** 所以校验分三段，缺一段都不算验过。

| 段 | 查什么 | 谁来做 | 不通过怎么办 |
|---|---|---|---|
| 一、语法 | 渲染器会不会报错 | 脚本 | 改到 PASS，没有例外 |
| 二、结构 | 信息有没有缺、有没有假 | 逐条过清单 | 缺就回去补，不硬交付 |
| 三、视觉 | 会不会压字、溢出、错位 | 渲染 + 人眼 | 调坐标或改标签 |

## 一、语法校验

```bash
python3 scripts/check_mermaid.py path/to/diagram.mmd
python3 scripts/check_mermaid.py path/to/example.md
python3 scripts/check_drawio.py path/to/diagram.drawio
```

退出码：`0` 全绿 / `1` 有错误 / `2` 只有警告。

**有错误必须改到 0，不能"大概能渲染"。** 有警告也要逐条看——多数警告是真问题（孤岛节点通常意味着漏了一条边）。

## 二、结构校验

脚本查不出「这条分支业务上不存在」，只能人过清单。

### 流程图五条

1. 每个角色一条泳道，泳道里只放该角色的动作
2. 主干从头走到尾，无断链、无孤岛
3. 每条异常都有**触发条件**，且都有出口（回流某步 或 终止）
4. 跨泳道交接点写清「谁交给谁、交的是什么」
5. 虚线只用于异常与可选路径

### 架构图五条

1. 每个模块都能对应到真实功能——**没有为了凑数画的框**
2. 模块没有跨层错位（有业务规则的都落在核心域）
3. 层内模块数 ≤8，层的总宽不溢出画布
4. 没有反向依赖；若刻意保留，图上已标注
5. 决策带里的结论与正文一致，没有互相矛盾

第 1 条最容易被忽略。判断方法：**指着每个模块问「这一格对应产品里的哪个操作？」，答不上来的删掉。**

## 三、视觉校验

### draw.io 渲染预览

```bash
python3 scripts/check_drawio.py path/to/diagram.drawio --preview
# 同目录生成 diagram-preview.svg
```

再截图看一眼：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars \
  --window-size=1680,1100 \
  --screenshot=/tmp/preview.png \
  "file://$PWD/diagram-preview.svg"
```

窗口尺寸要比画布大一圈，否则截出来右下角是白的。**Chrome headless 最小窗宽 500px**，看窄屏效果时按 500 起算，不要按 390 截——那是假象。

### 肉眼要看的四件事

| 症状 | 原因 | 改法 |
|---|---|---|
| 文字压出框 | 标签超过 18 字，或模块宽 <150 | 拆标签，或加宽模块 |
| 层带右侧留白大 | 模块宽取整后余数没分掉 | 最后一个模块吃掉余数 |
| 箭头穿过节点 | 跨泳道节点没对齐列号 | 让交接点同列 |
| 决策带/图例被截 | 画布高度没跟着内容增长 | 画布尺寸按内容最大边界算，别写死 |

### Mermaid 视觉校验

Mermaid 没法本地渲染，用两种办法之一：

- 贴进 <https://mermaid.live> 看
- 交给用户在 Obsidian / 编辑器的预览里看，并主动说明「泳道是 `subgraph` 模拟的，不是原生容器」

**不要假装看过 Mermaid 的渲染结果。** 没渲染就说没渲染，让用户确认一下。

## 失败排查顺序

按这个顺序查，别乱试：

1. 解析失败 → 先看 `end` 配平（占失败原因一半以上）
2. 节点变方块里一串问号 → ID 用了中文
3. 标签被截断 → 缺双引号
4. 图打不开 → drawio 的 `id="0"` / `id="1"` 丢了
5. 打开后报错 → 有悬空的 `source`/`target`
6. 节点压住泳道标题 → 横向泳道里 `x < startSize`
7. 渲染出来一片散点 → 有节点没连边

## 交付前最后一遍

- [ ] `check_mermaid.py` / `check_drawio.py` 退出码为 0
- [ ] 结构清单两面都过完
- [ ] 预览截图看过，无压字、无溢出
- [ ] 分层说明四段齐全，且没有复述箭头
- [ ] 「待确认」项已列给用户
- [ ] 交付话术里写明了打开方式
